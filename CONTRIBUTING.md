# Contributing

Thanks for taking the time to contribute. This repository is the **public backlog** for the Dendri project — anyone can file bugs, request features, or ask questions here.

## What we accept

- **Bug reports** — use the [bug template](./.github/ISSUE_TEMPLATE/bug_report.yml).
- **Feature requests** — use the [feature template](./.github/ISSUE_TEMPLATE/feature_request.yml).
- **Questions** — please use [Discussions](https://github.com/afterrealism/dendri-backlog/discussions), not Issues.
- **Security reports** — privately, via the [Security tab](https://github.com/afterrealism/dendri-backlog/security). See [SECURITY.md](./SECURITY.md).

## Before you file

1. **Search existing issues** (open and closed). If a matching issue exists, add a comment instead of opening a new one.
2. **Use the latest version** of the affected component. Many issues are already fixed.
3. **Pick the matching template.** Blank issues are disabled on purpose — the templates ask for the info we need to act.
4. **Be specific.** Include versions, environment, and exact reproduction steps. "It doesn't work" cannot be triaged.

## What to expect

- Issues are auto-labeled `triage` and reviewed on a **best-effort basis — no SLA**.
- Maintainers will add `type:*`, `component:*`, `priority:*`, and `status:*` labels as they triage.
- If we ask for more info and don't hear back in 14 days, the issue may be closed. Reopen it whenever you have the info.
- Accepted work moves into the public Project board.

## Code of conduct

By participating in this repository — filing issues, commenting, or otherwise — you agree to abide by the [Code of Conduct](./CODE_OF_CONDUCT.md). Please be kind; maintainers are a small team and most users are here for free.

## Code contributions

This repository contains no source code, so we don't accept code PRs here (small docs fixes excepted). For source contributions, see the upstream Dendri repositories linked from the project README.
